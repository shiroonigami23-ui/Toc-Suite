One rule per line: S -> a S b | ε. Upper-case letters (S, A1, E') or <name> are non-terminals. Write ε as ε, eps or an empty alternative. Separate multi-character symbols with spaces (E -> E + T | id).

Every parse tree of the test string (up to two). Two different trees for the same string prove the grammar is ambiguous.

The Cocke–Younger–Kasami algorithm on the Chomsky-normal-form grammar. Cell (i, ℓ) lists the non-terminals that derive the ℓ symbols starting at position i; the string is in the language when the start symbol is in the top cell.

Pick a pumping length p and a witness w. The checker tries every legal decomposition and looks for one that stays in the language when pumped (i = 0, 2, 3). If none survives, w is a good witness for this p — the proof then repeats the same argument for every p.

Full regular expressions: + or | for union, * for star, ? for optional, parentheses and ε. Opens in the Finite Automata studio.
